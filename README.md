# Throttle & Steel

A single-page, motorbike-dealership landing page concept — dark asphalt palette, 
condensed industrial typography, and an ember-red/amber accent scheme designed 
to feel fast and mechanical.

## Features
- Full-height hero section with a diagonal glowing "speed line" accent
- Skewed CTA buttons that mimic motion
- Responsive navbar (Bootstrap 4 collapse/toggle)
- "The Fleet" section showcasing four motorcycle categories 
  (cruiser, sportbike, vintage, off-road) with photos, specs, and pricing
- Fully responsive down to mobile, with two breakpoints for the hero typography

## Built with
- HTML5 & CSS3 (custom properties for theming)
- [Bootstrap 4.5.2](https://getbootstrap.com/) for layout/navbar behavior
- Google Fonts: Bebas Neue (display) + Barlow Condensed (body/UI)
- Photos via [Unsplash](https://unsplash.com/license)

## Usage
Open `throttle-and-steel.html` directly in a browser, or rename it to 
`index.html` and enable GitHub Pages to host it live.
